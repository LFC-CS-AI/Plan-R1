## 已执行检索路径与停止规则

| 步骤 | 实际检索/核对 | 结果与边界 |
|---|---|---|
| Root定位 | 精确题名Plan-R1 + Safe and Feasible；ICLR proceedings、作者GitHub、OpenReview | 取得正式21页PDF；不是只读abstract |
| Backward | 正式References印刷pp10–13；§1–3与表1交叉核对 | 核12条Root→P引用；书目即使写preprint也再查当前正式状态 |
| Token扩展 | MotionLM、Trajeglish、SMART全文及作者网站 | 保留独立假设/同刻分解；不以时间先后建立EXTENDS |
| IL/RL规划 | PlanTF、PLUTO、PDM、CarPlanner、Gen-Drive及Diffusion Planner原文 | 对照训练信号、反应设定、后处理和controller |
| Forward发现 | 精确Plan-R1题名及RL、planning、2026；发现后读原始References | 核SMART-R1、PlannerRFT均引用2025preprint；补核NoRD [39]为ICLR2026书目 |
| 二层扩展 | SMART-R1 References→CAT-K；CAT-K Related Work→SMART/Trajeglish对照 | P13距Root两层；没有递归扩展到第三层 |
| 新近线索 | NoRD精确题名；R2SE正式IEEE记录；后续2026/2608/2609检索 | 新近查询有大量无关“plan/R1”结果；不把低召回解释成没有更新工作 |
| 排重 | CAT-K+RFT；std移除+驾驶；纵横探索+survival；RL Adapter+controller | 已有相近组合使简单叠加缺乏首创依据；记录在combinations，不开始实验 |

没有取得一个覆盖全网的完整forward citation列表，也没有声称“最新研究已经穷尽”。检索是根中心、两层、有截止日的首批抽样；新近线索进入待办，不能靠标题填满卡片。

### 访问失败与替代来源

- OpenReview直接pdf/forum部分请求返回browser verification；采用ICLR proceedings或作者固定arXiv正文，保留正式状态的独立来源。
- CVF的MotionLM早期PDF请求内部错误；改用arXiv v1全文及CVF书目。PlannerRFT最终PDF返回403，未绕过；采用arXiv v1，最终作者差异保留。
- 部分猜测的arXiv HTML版本不存在（404）；之后读取可验证的v1/v2/v3，不以404推定论文不存在。
- PDF截图工具不可用；PDF表格以文本抽取、表caption及必要的作者网页交叉核对。数学排版歧义明确留待人工复核。
- shell git fetch无法连接环境proxy；仓库main与远端元数据使用GitHub连接器核验，后续提交亦用连接器。没有绕过网络策略。
