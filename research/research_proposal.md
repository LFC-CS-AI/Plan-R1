# Plan-R1 第一阶段研究决策与下一步方案

日期：2026-10-20。本文是基于真实源码审计、CPU 机制实验和公开文献的立项建议；没有真实 nuPlan 闭环结果，也没有已证明的新算法。

## A. 信用分配问题是否值得继续？

**不建议按原命题继续立项。** “Plan-R1 的早期动作得不到后续风险反馈”与其实际累计优势实现不符。仅补 return-to-go 是重复已有机制；仅加 counterfactual baseline 则与长期信用分配研究重叠，而且本次 toy 中 RTG、VD 和 RLOO 均已有效降低风险，反事实法没有显示决定性的最终收益优势。

**值得保留一段短期、可否证的诊断工作。** 更准确的问题是：混合 process/outcome reward、动作依赖终止和组中心共同作用时，训练的估计目标是否与我们声明的规划目标一致？源码显示整轨迹 outcome 可受首次违规后的屏蔽后缀影响；固定时长简化条件下，自包含基线还会对不同时间的 score-gradient 施加不同缩放。但基础修复、RLOO 或 terminal-only outcome 很可能已经足够。这类结果适合复现说明、实证分析或方法论文中的基线修正，**单独不足以认定有 CCF B/A 级贡献**。

投入上限建议为一至两周的 CPU/小缓存研究；若目标一致的 RTG+RLOO 已消除主要差异，就停止把“信用分配公式”当主线。

## B. 有哪些更有潜力的拓展方向？

| 方向 | 与 Plan-R1 的联系 | 创新风险与建议 |
|---|---|---|
| 反应性交通下可靠的分支风险排序 | 当前训练以 top-1 周车预测评价不同 ego token，缺少选中分支的风险可靠性控制 | **优先作为待验证问题**；需超出 AD-WM 的动作可辨别性和已有 robust conformal planning |
| mixed reward / 随机终止下目标一致的无 critic 优化 | 当前 outcome 广播、有效 token 长度归一化和后缀 outcome 影响有具体源码证据 | 最适合先做便宜诊断；简单修复的新颖性较弱 |
| 对抗世界模型、自博弈、CVaR | 可从冻结 predictor 和长尾场景自然扩展 | AWM 已直接沿 Plan-R1 做相关工作，不推荐泛化版本 |
| 风险 critic、自纠错与按需延长 imagination | 与 motion token 的逐步生成适配 | CorrectionPlanner、RISE 等已覆盖核心机制，不推荐只拼模块 |
| 连续时间安全与 motion token 量化误差 | 原 reward 主要检查离散 token 位置，可能漏掉区间风险 | 可作为第二候选，但需要与连续碰撞检测、可达性、既有安全滤波方法做专门查新；本次未验证独立新颖性 |

## C. 最推荐的 CCF B/A 研究起点

**推荐起点：在固定世界模型调用预算下，学习并校准“ego 干预导致的周车反应风险差”，使错误安全排序可检测、可拒判。**

推荐的是这个可检验问题，**不是声称“风险排序+校准+分支”组合已经新颖**。其价值在于直接面对 world-model RL 的决策瓶颈，也不依赖“Plan-R1 没有累计优势”这一错误前提。若无法展示相对下述最近邻的实质差别，不建议以此申请长期算力或锁定会议。

暂定题目：*Decision-Calibrated Reactive Branching for Tokenized Planning*（仅工作标题，不是现有论文或已实现算法）。

### 1. 精确定义研究对象

对同一真实可复位前缀 h_t，比较替代 ego motion token a 与参照 token a′。之后继续执行同一个闭环 ego policy，周车按干预后的状态重新响应：

\[
Q_R(h_t,a)=E\left[\mathbf1\{\text{首次碰撞发生于 }[t,t+H]\}
\mid do(a_t=a),h_t,\pi_{future}\right],
\]

\[
\Delta_R(h_t,a,a')=Q_R(h_t,a)-Q_R(h_t,a').
\]

这里的 Δ 是在给定 simulator 下的**干预风险差**。若想讨论“这一次具体 episode 本来会怎样”的个体反事实，必须另外给出 latent randomness 的识别/abduction 假设；不把 action-conditioned rollout 自动叫作已识别的真实因果反事实。

必须区分：对已有 prefix 的替代动作比较，与重新采整条无共享前缀的候选轨迹比较；固定周车轨迹的 direct effect，与周车重新反应后的 total effect；平均 reward 排序，与安全事件概率差排序；人口平均风险校准，与被 planner 选中的动作上的风险可靠性。

### 2. 待验证假设

H1：在控制 token 采样预算和终止语义后，真实风险排序错误比优势估计方差更能解释失败。**当前未验证。**

H2：同前缀、成对分支得到的风险差误差，比平均 ADE/FDE 更适合决定何时接受某个候选动作。AD-WM 已提供相关思想，**不能把这个观察本身当创新**。

H3：对“ego 改变周车反应”这一子类场景，构建干预强度/反应性条件下的成对误差界，并在自适应选择后仍控制错误接受率，能在相同预算下改善安全与通行效率的折中。**这是拟争取的新方法内容，尚无实证或理论保证。**

### 3. 方法草案与需要证明的内容

先固定一个清楚的规划目标：最大化效率/舒适度，同时限制首次碰撞概率，而不是依赖安全门控的软分数自动实现硬安全。将已有 RTG/RLOO 作为基础估计，process reward 按实际有效步计，outcome 只在已声明的 episode 结束处记一次。此部分属于标准基线建设。

对选定前缀 fork 候选 ego token，后续 ego 和周车都重新 rollout。用共享 simulator 随机数配对来减小差值方差；共享 seed 只是一种耦合，须固定对应的随机变量与采样顺序，不能声称现实个体反事实已因此识别。

从独立校准集估计 Δ 的残差区间 `[L(h,a,a′),U(h,a,a′)]`。若 U<0 才接受“a 比 a′ 更安全”的判断；若区间含零则追加预算或保留参照。**这个接受规则本身是常规统计决策，不作为创新。** 拟研究的难点是如何在强反应性、非独立候选、planner 自适应选分支和预算停止下仍有有效误差控制，且不退化成全拒判/一直刹停。

需争取证明的命题：在明确的 calibration exchangeability、反应性漂移界或合法在线误差控制条件下，适应性选择后错误安全排序的接受概率不超过 ε；并给出预算/风险差 margin/反应性强度之间的界。不能用普通 marginal conformal coverage 冒充任意 h、任意 OOD 的 conditional 保证。若只在强 simulator 可复位假设下成立，必须写明该限制。

候选预算分配可用置信区间宽度和可改变决策的收益，但 VIP/RISE 已有相关机制，不能另计一项创新。训练中若把风险差作为 action-dependent reward/baseline，还需推导它究竟优化什么目标；任意替换 return 并不自动保持无偏或最优策略。

### 4. 最近邻的逐项排除要求

| 最近邻 | 已有内容 | 本项目必须新增并实证的差异 |
|---|---|---|
| COCOA、Mesnard、Shapley credit | 长期/反事实贡献及估计问题 | reactive traffic 中模型风险差的可靠性，不只更细归因 |
| 驾驶 CRAFT | counterfactual proxy + grounded residual | 被自适应选择的同前缀风险差错误接受控制，而非再做 proxy/residual |
| AWM | Plan-R1 对抗周车、联盟归因和尾风险 | 校准风险差的可靠性；不能把对抗生成器作为主要新模块 |
| AD-WM | action discrimination 和 decision-relevant 诊断 | 面向稀有安全事件、周车反馈及选择后的可靠性，而非换表示损失 |
| RISE、VIP | 风险/收益或方差驱动计算分配 | 若无新的可靠性-预算结果，单独分配预算不算新增贡献 |
| Interactive robust conformal planning；Conformal Policy Control | 交互式 shift 和风险控制 | 需全文确认它们是否已涵盖本项目所需的选择/停止条件；若已涵盖，应停掉相应创新主张 |

本文尚未完成这些最近邻全部正文证明的逐式排除；因此**独立新颖性状态为“未确证”**。不以“尚未发现相同标题”作为创新证明。

### 5. 不用 GPU 的下一轮否证实验

建立有 ego 和一辆 reactive 周车的二维小型环境；周车按 latent aggressiveness、让行阈值响应 ego 的实际位置/速度。可精确复位 h_t、噪声及隐藏参数，对每个候选 ego 动作用充分 rollout 估计风险差参考值。按场景 seed 而非单条 trajectory 划分 train/calibration/test，避免共享前缀泄漏。

固定因果目标后比较：原 VD、RTG+RLOO、固定预算随机 branching、单预测器 top-1、同预算多模态模型/ensemble、固定置信区间门控、AD-WM 风格动作可辨别性基线、已有校准控制基线，以及拟议方法。训练 policy 的实验与只检验风险估计器的实验分开报告。

预注册主要指标：选中动作的安全排序错误率、错误安全接受率、风险差区间覆盖与宽度、碰撞率、进度、拒判率/保守性、模型调用数、真实 wall-clock。按可恢复/不可恢复、周车反应强弱、罕见分支、隐藏行为漂移分层。不得只报平均 return 或 ADE，也不得把更长 rollout 当方法增益。

终止判据（这些是未来门槛，不是已取得结果）：

1. 若换成目标一致 RTG/RLOO 后没有可观风险排序问题，停掉该动机。
2. 若独立 simulator 的随机数耦合方式一变，收益就消失，说明依赖脆弱模型假设，不能宣称真实因果归因。
3. 若同预算 ensemble+标准校准就达到同等表现，且理论没有新增条件，停掉方法新颖性主张。
4. 若错误接受率下降仅来自几乎全拒判或显著降低进度，方法不合格。
5. 若最近邻全文已经覆盖所需保证，不继续以此作为独立论文核心。

### 6. 后续 CCF B/A 证据门槛

CPU 阶段只能决定机制是否值得上真实基准。进入下一阶段至少需要：跨环境的独立方法贡献；明确且可验证的保证/目标；与强便宜基线和最近邻的公平比较；多个随机 seed、按场景统计的置信区间；在冻结 world model 与独立 reactive evaluator 间的验证；nuPlan/interPlan 等真实闭环场景的安全-进度-计算成本曲线。替换一个优势公式再提高若干 toy 分数不满足要求。

会议选择应以能否提供独立方法、理论或跨基准证据为依据，先考虑接收学习式规划方法的 AI/机器人会议，再按成果强度匹配 CCF B/A 目标。具体会议等级、当年指南和截止日期须在确定投稿时通过官方目录与 CFP 核实；本文没有做这些时效性核实，也不承诺录用。

## 研究决定

当前应把原始信用分配主线降级为基础诊断，**优先用短周期验证“反应性分支风险差的可靠性”**。现有材料足以支持做这一步探索，尚不足以宣布已经找到了真正独立的新方法。若上述新颖性和等预算门槛失败，应明确终止立项，而不是带着未证实的 Plan-R1 缺陷进入完整训练。
