# 环境、目标与统计口径

## 与第一阶段的关系

沿用 `../plan_r1_analysis.md` §7 的源码事实：训练中周车使用 top-k=1 预测，ego 在 top-50 内采样；世界模型冻结，没有在这段循环内做 ensemble/风险校准。第二阶段只检验由此启发的机制假设，**没有运行 Plan-R1、没有检验其真实碰撞成绩**，也没有重新运行第一阶段实验。本文中的 world model 是小型代理，不是原模型的缩小复现。

## 独立模拟器与预测器

`reference_simulator.py:evaluate` 在二维垂直路口模拟两辆矩形车。ego 沿 x、周车沿 y 行驶；周车具有随机让行意愿、延迟感知、有限 jerk/制动力和有记忆的让行状态。ego 的5个候选为持续紧急停车，以及先减速/匀速/加速1/加速2后滑行；完整轨迹8秒，dt=0.08秒。周车会依据每个 ego 候选重新反应，共享外生随机数仅用于成对潜在结果；不是把一条固定周车轨迹放到所有候选上。

`world_model.py:predict` 使用解析到达时间区间、逻辑回归让行概率和常数让行延迟；训练时拟合64个参考场景的响应统计，4个 ensemble 成员为场景 bootstrap 拟合。它没有导入参考动态、碰撞例程、真实隐藏参数或测试标签，缺少参考器的 jerk、感知历史和 yield latch。二者共享场景/动作定义和基本几何尺度，因而这里只是**结构错设下的机制实验**，不构成跨域泛化证明。

场景是固定范围的均匀采样，未按失败筛选。距离18–30m、ego速度7–10m/s、周车速度6–10m/s，以相对到达时差生成周车距离。三档反应强度0/0.65/1.3；0档是无反应负对照。ID周车让行意愿0.7、平均延迟0.24秒；`driver_shift` 为0.4、0.55秒并有1m隐藏位置偏置。后者的改变没有体现在模型输入中，模型预测在两个域完全相同：这是明确违反校准交换性的**隐藏行为漂移压力测试**。额外模型采样不能凭空识别这种漂移，失败不能证明任何可实现算法应有任意 OOD 保证。

每个种子独立生成 train/cal/test=64/64/48个场景，种子101/202/303/404。三个强度、两域共1152个测试场景实例；不同强度/域共享初始场景以配对，不能声称1152个完全独立的初始几何。每候选2048个独立参考 rollout 估计风险。训练与校准分别256/512个 rollout；另有与参考估计独立的单次部署潜在结果库，同一场景在方法间配对。参考器为模拟环境内真值的 Monte Carlo 估计，并非物理世界真值。

## 基线的准确含义

| 方法 | 实际计算 | 限制 |
|---|---|---|
| deterministic | 中心噪声+最可能让行分支，输出0/1碰撞 | 每场景仅5个有用调用；同一确定性输出重复不增加信息 |
| mc | 单个拟合成员的随机预测 | 仅覆盖该模型内随机性 |
| ensemble | 4个 bootstrap 成员、等额随机预测 | 不自动覆盖共同结构偏差 |
| binomial_union | 每成员 exact Clopper–Pearson，再成员/动作 union 后取平均上界 | 控制模型内采样误差，非真实环境偏差 |
| paired_difference | CRN 耦合候选与 coast；界定风险差，再结合绝对风险点估计筛选 | 对比基准也可能危险；不提供绝对真实风险证书 |
| residual_calibration | 用 ID 校准场景拟合全局风险截距 | grounded proxy correction 的最简对照，不是 CRAFT |
| marginal_cp | 池化 scene/action 残差分位数 | 同场景动作相关，且选择后覆盖不能直接继承；仅作常用朴素基线 |
| simultaneous_cp | 场景内最大动作残差的 split conformal 分位数 | 在交换性等条件下可保护数据依赖的动作选择；可能保守 |
| worst_member | 成员经验风险最大值 | 最简 robust aggregation，不是 AWM 对手训练 |
| action_residual | 每个动作单独拟合风险截距 | 看主结果后新增的常规控制，未用测试标签拟合；不是预注册结果 |
| actionwise_cp | 每个动作单独校准分位数 | 未对动作选择 union，不能声称 simultaneous guarantee；同为事后控制 |

每种方法都按风险分数≤0.1筛选，再选择名义无碰撞进度最高的候选，空集则停车。差分法还要求相对 coast 的风险差上界≤0.03；coast本身只受绝对风险点估计筛选。方法使用不同保守性，不能只看碰撞率判优。分位数取 `ceil((N+1)(1−alpha))`，alpha=0.1；参考校准标签用额外 union 校正的99% Monte Carlo上界。`simultaneous_cp` 的通常覆盖论证需要场景/预测随机性可交换、训练模型独立、校准标签足够准确；粗略外加标签失败概率后是 alpha+0.01 的边际量级，不是逐场景保证。

deterministic把单条中心预测转换为0/1风险，是刻意保留的弱起点，不是校准良好的概率模型。它与MC的差异也包含普通多模态不确定性，不能全部归因于反应性，更不能当作Plan-R1的等价实现。让行/不让行两模式的低成本加权积分、上下文残差模型也是下一轮应补的普通基线；本轮尚未运行，故不能宣称廉价方案已经穷尽。

## 指标与误差分解

设模拟环境风险 `q(s,a)=P(collision|s,do(a))`，代理估计 `p̂`，最终选择 `a*`，非停车接受指示I。

- **排序错误**：只统计非停车动作对，且参考99%区间分离超过0.05的对；严格逆序记1、预测打平记0.5。`ranking_decomposition.csv` 同时给出严格逆序与平局计数。二值 deterministic 的大量平局不是严格反向排序；这项 tie-aware 指标不能单独证明因果。
- **错误安全接受**：`I × 1{q(s,a*)>0.1}`。同时报告全场景比例与除以接受数的条件比例；全拒判时条件比例是NA，不能写0。另列参考区间下界>0.1的 definite 版本。阈值附近估计存在 Monte Carlo 不确定性。
- **部署碰撞率**：独立单次部署的实际0/1结果。**期望碰撞率**：跨场景平均 `q(s,a*)`；这两个量均报告，有限部署场景会使其不同。
- **进度**：碰撞前实际前进米数及 Monte Carlo 期望。`progress/oracle` 的分母是“用参考风险替换预测风险、仍按相同名义进度规则选动作”的结果；**不是**对真实期望进度求解的最优策略。比值>1可能来自危险动作，不能解释为更优安全性能。
- **拒判比例**：选择停车的比例。停车也有少量前进距离，但在该几何范围内始终在冲突区外停住；不能用它证明真实道路紧急停车普遍安全。
- **选择关联诊断**：`selection_failure_modes.csv` 区分错误接受时是否存在安全的非停车替代、所选风险是否严格反排到该替代前面。它比“其他动作对有逆序，同时发生碰撞”更接近假设，但仍不是真实驾驶因果识别。
- AD-WM 风格 **top-1 elite regret**：在非停车动作中取预测风险最小者（平局取更高名义进度），以参考风险减最小参考风险，并除参考风险范围。它是诊断，不是实际筛选器的损失或新贡献。

summary 的95%区间为400次两级 bootstrap：先重采样4个种子簇，再采样簇内场景。只有4个种子，区间仍不稳定；并未证明逐场景安全。零事件额外给 exact-binomial 上限，但共享拟合/校准导致依赖，不能把该补充界当完美有效的跨簇保证。经验立项门槛“条件错误接受≤5%、进度比≥80%”与 alpha=0.1 的边际 CP 定理是**不同对象**。

## 预算和实际耗时

B=80/320/1280，每个场景5候选。一次“模型调用”指一个候选的完整随机区间预测结果，非 Python 函数调用、非 token、非 Plan-R1 神经网络 forward；所有随机方法严格用满 B。确定性只用5次并在三档预算重复展示，不虚构额外调用。候选数、时长固定，不比较 ADE/FDE。

在线时间由 `perf_counter` 测量真实 CPU-only 批量执行的 elapsed wall time，含方法内筛选，不含参考器和校准；逐行时间是批量时间/场景数，不是在线单场景延迟测量。离线训练参考、校准参考、校准预测、测试参考/部署均在 ledger 分列。校准法使用额外带标签数据，不能宣称与无标签方法的总信息/算力预算完全相同；拟合参考/模型可复用，原始 ledger 仍完整记账。

当前是单次8秒候选选择，不是反复闭环重规划，也没有训练策略。Python3.9.25、NumPy1.24.4、SciPy1.10.1、Matplotlib3.9.4；无 GPU、权重或大型数据。小型统计拟合不等于训练完整世界模型。
