# 立项判断：目前 NO-GO，新方法创新尚未成立

**不建议直接以“反应性风险排序+选择后校准”为题投入 CCF B/A 论文开发。建议只保留一轮有退出门槛的真实模型验证。** 玩具机制存在，但廉价多样本预测已解决大部分失败；剩余失败未被证明主要由排序引起；最近邻已覆盖许多被认为新的问题。这里的 NO-GO 是当前证据下的立项判断，不是断言这个领域不存在进一步方法空间。

## 1. 假设到底验证到哪一步

原假设包含两层：世界模型可能排错；排错会使规划器选择危险动作。前者在独立实现的 reactive toy 中成立。后者对单一确定性基线有具体场景证据，但对强普通 ensemble 的剩余问题支持不足。

强反应、ID、B=1280 时，确定性选择192次中有100次错误安全接受，其中65次有安全通行替代，只有3次满足“所选动作与该安全替代严格逆序且参考区间明显分离”。其余可能是分数平局、错误阈值或选择偏好，不能全部归于严格排序颠倒。ensemble 只剩3/98次错误接受，三例均无安全非停车替代；shift 下对应9/98，也均无安全非停车替代。此处需要的是识别应当停车、修正绝对风险低估，不能用排序故事代替。

特别地，ID强反应 deterministic 的 tie-aware 排序错率42.93%中，平局占全部可区分动作对81%，严格逆序仅2.43%；ensemble 的严格逆序反而为9.29%，虽然 tie-aware 错率降至9.50%、期望碰撞显著下降。**“减少严格逆序一定降低碰撞”没有得到本轮支持。**

## 2. 终止条件的实际执行

普通 ensemble 将 ID强反应期望碰撞从15.91%降到0.81%，但进度比为75.41%，未同时满足预先写下的5%/80%经验门槛。事后补充的普通逐动作 residual 在该条件点估计为4.8%错误接受、86.71%进度比，已达到门槛，95%区间却仍很宽，不能宣布已统计解决。中等反应下 ensemble 的点估计本身也达到门槛。不能在看到这些结果后再改实验，把简单方法人为排除。

global/max-over-actions CP 全拒判，不能靠零碰撞宣布解决；逐动作 CP 在这里也全拒判，可能是弱预测器、校准样本有限和标签上界共同造成，未检验更强局部/条件化常规校准。hidden-driver shift 不满足交换性，不能以此声称现有 CP 理论失败。预算增加对整体表现有帮助但并非严格单调；不挑种子、不挑预算报告。

因此：没有获得“所有普通基线已解决”的证据，也**没有获得足以支持新方法研发的稳健剩余问题**。前一否定不能自动推出后一肯定。

## 3. 文献覆盖后的新颖性边界

- AD-WM 已比较候选排序和被选中 elite 的实际 regret；仅增加 selection-aware 指标不是新贡献。
- RISE 已有风险配对监督及按预期规划收益/成本分配想象深度；“哪里危险多想几步”不是新贡献。
- CRAFT 已以真实执行纠正反事实代理；AWM 已沿 Plan-R1 做反应性对抗、regret和尾风险。
- Interactive robust CP 已在有响应敏感性约束的系统控制策略引发的环境漂移；CPC 已控制数据依赖的策略选择/部分反馈漂移。不能声称首次处理反应性或选择后风险。
- 我们的 conditional false-safe 比例不是 CPC 的 population expected loss。先改变 estimand 再观察已有定理不适用，不能直接算方法创新。固定动作库的 simultaneous coverage 也是常规做法。

本轮没有复现这些论文的完整系统，尤其没有满足 robust CP/CPC 的原始假设。它们“尚未被本实验覆盖”不等于已被我们击败；没有发现同一定理也不等于检索证明空白。

## 4. 唯一保留的条件性研究方案

**反应模式切换下的选择安全与预算界。** 仅当真实模型验证通过后，考虑对可观测/可估计的交互响应模式建立风险偏差包络，用模型内成对风险差置信序列和有限真实校准反馈决定接受、继续采样或停车。绝对安全基准与风险差需同时约束；额外模型样本不能消除结构误差。

与 RISE 的可能区别须是可证明的 fixed-budget/anytime 错误接受控制与必要预算界，非学习一个 gate；与 robust CP 的可能区别须是在明确的分段响应条件下减少全局 Lipschitz tube 的保守性，且**给出相近假设下的比较**；与 CPC 的可能区别须是可检验的有限动作/选择事件风险界，且解释条件事件和总体期望之间的代价。以上均为待证明目标，尚无新定理、实现或创新确认。

普通 sequential testing、局部 CP、group calibration、importance weighting 已是成熟组件。若最后只是拼接它们，应停止新方法立项；隐藏模式不可观测且无额外真实反馈时，还应先证明可识别性/不可能性边界，不能承诺任意 shift 安全。

## 5. 继续冲击 CCF B/A 前缺少的关键证据

1. **真实学习世界模型的可复现剩余失败**：冻结 Plan-R1 或可访问的轻型动作条件模型，在独立 reactive simulator 中做同初态ego干预；匹配候选、rollout、数据和 CPU/GPU 时间，分离 rank、tie、absolute calibration。当前没有运行这项实验。
2. **强廉价基线仍无法达到安全-进度前沿**：增加未参与本轮设计的新场景/新种子，比较动作/上下文校准、让行两模式加权积分、更丰富 ensemble、配对估计和可合理实现的最近邻。当前确定性0/1风险是弱起点，不能把普通概率混合的收益当成新发现。不得在当前测试集上选最佳超参/方法后当泛化成绩。
3. **因果关联**：对同一预测器分别纠正排序和绝对风险，诊断哪种干预改变最终动作/碰撞；证明剩余失败不只是“所有通行动作都危险却没停车”。
4. **理论和数据条件**：定义具体控制量；验证响应/支持/交换性或漂移包络，处理自适应选样/停止；在相同假设下对现有 robust CP/CPC/序贯风险界有实质改进。
5. **跨环境与真实闭环证据**：多个互动类型、独立 driver model、长时重规划、足够独立场景的稀有事件区间和真实模型调用耗时。toy 当前没有足够统计力，也不能推断 Plan-R1 基准缺陷。

下一步只推荐有限规模的第1–3项验证，暂不训练完整策略。若普通上下文校准已足够、或真实失败主要来自不可观测分布漂移，停止此排序新方法方向。若验证未通过，不推荐再凭空指定另一个“更创新”的 Plan-R1 方向；应先从可复现失效机制重新选题。
