# 受约束组件实验：事先固定的协议与解释边界

初版配置 `protocol.json` 在数据和训练前写入；没有根据测试集调整阈值、epoch、限值或网络。v1 的200Hz标签随后被独立区间器发现混叠，v2固定数值修正为局部连续最小化，并同步修正边界构造。v1全部代码/数据/结果保留，不混入主结果；测试种子复用，因此不是预注册盲测，修正不改变训练/测试场景相互分离。先导只做词表/动力学容量探针，不运行既有阶段的几何漏检统计。JSON序列化与vectorization广播错误的日志亦保留。没有筛除碰撞训练样本或根据 Bridge 是否成功来构造场景。

## 轨迹族和物理条件

直接读取原始 `tokens/tokens_1024.pt` 的 Vehicle 1024×3 原定义，0.5秒 SE(2) 端点 `(dx,dy,dyaw)`。不是预训练策略采样。选取正向位移2.5–10m、绝对 yaw≤0.1 的词表项，同一 token 连续使用两次，形成 0/.5/1s 三个位姿。这个受控选择不代表真实 token 频率，也没有覆盖任意两 token 的组合。

全局七阶多项式 `p0(t)` 最小化 `∫₀¹||p'''||²dt`，满足三个位置、.5/1s 的航向切向、共同初始速度/加速度。初态只确定一次：`v0=||z_xy||/.5`、纵向加速度0、`κ0=z_yaw/||z_xy||`，横向加速度 `v0²κ0`。**这是受控合成初态，尚未与真实历史匹配。** 全局多项式天然跨 .5s 为 C2；不是分别拟合两段再忽略连接。切向速度必须为正。固定桥即该 `p0`；常规线性插值通常不满足共享初始航向/加速度，因此不作为受约束可执行基线。

Bridge 输出一个系数，解码 `p(t)=p0(τ(t))`，`τ=t+c t³(t−.5)(t−1)`。`τ(0,.5,1)=(0,.5,1)`，`τ'(0)=1, τ''(0)=0`，故所有 token 位姿、初始速度、加速度和曲率精确保留；正单调 warp 保持航向。输出是运动学无侧滑路径：`ψ=atan2(p'_y,p'_x)`、`v=||p'||`、`κ=cross(p',p'')/v³`。不是轮胎/执行器完整动力学，也没有跟踪误差、转向变化率、闭环/递归安全保证。

限值固定为速度2–30m/s、加速度向量≤4m/s²、jerk≤8m/s³、曲率≤0.2m⁻¹、yaw rate≤0.6rad/s。Bernstein 系数包络和链式法则对整个时间区间、所有 `|c|≤cmax` 做充分证书；二分系数幅值并乘0.98。它比较保守，不能把未获证书的词表项称为物理上不可行，也不能把所得小容量当作所有桥族的上界。

普通残差基线 `p0(t+c t³)` 同样共享初始状态/C2 和动力学限值，但可改变端点。它是**纵向时间残差组件**，不是所有 XY 轨迹残差架构的全面复现。另设投影残差：将 `t³` 加入保持端点的最低阶修正得到 `t³−3t⁴+2t⁵=2t³(t−.5)(t−1)`，与 Bridge 完全等价。它是函数族等价性对照，不伪装成独立训练第四个模型。

## 场景、标签和公平性

训练768、验证192、独立场景种子测试512。各一半 broad 场景和一半 boundary 场景。broad 随机周车位置/速度；boundary 在固定桥 c=0 的几何碰撞边界附近，以均匀目标 gap±3cm 平移周车，**未看 Bridge oracle 或学习输出**。后者刻意富集临界情况，不是现实发生率。所有周车用常速度刚体；没有使用世界模型或学习周车反应，亦不声称验证真实交通泛化。词表在三个 split 共享；独立的是交通场景，不是未见 token/地图/城市。

每场景两种轨迹族各9个等距系数，共18条轨迹，先以200Hz SAT找出所有局部极小值 bracket，再进行34轮向量化黄金分割连续时间最小化，端点亦包含，生成共同标签库。所有 Head 获得同一标签库，无额外教师调用或额外训练场景。损失 `sigmoid((.005−gap)/.006)+.02 max(0, nominal_final_x−final_x)`；min gap 是 SAT 分离裕量，负值不是穿透深度的欧氏距离。这是数值连续优化标签，**不是全局解析安全证明**；独立自适应区间器检查其分类一致性，明确保留 unknown。

三个 MLP 完全相同：12→32→32→9、tanh、1,769参数、同一初始化/Adam/批次顺序、200epoch×6step=1,200次更新，四个训练种子。验证集选 checkpoint，无测试调参。

| 方法 | 学习/输出 | 训练目标与边界 |
|---|---|---|
| reward_selector | 九个固定可行桥 primitive 的 argmax | 用连续标签库期望损失更新 logits；是“仅修复奖励”的**强组件代理**，未复现完整 Plan-R1 GRPO |
| residual_head | softmax 重心形成连续系数，普通时间残差 | 同标签插值损失；端点变化单独报告，不冒充同 token 方案 |
| bridge_head | softmax 重心形成连续系数，端点保持 warp | 同标签插值损失；原始生成轨迹直接评价，无外部安全器 |
| projected_residual | 对残差做精确端点约束 | 与 Bridge 的函数族/系数一一对应；用同一已训练权重检验恒等，不追加数据 |

固定桥、10Hz/50Hz过滤和九候选重排是廉价在线对照。过滤=拒判，**没有可执行安全停车备份**；拒判后的行驶/碰撞不建模。重排直接查询9候选几何，代价更大；不借此宣称同预算胜出。学习方法每次只有一次 Head 前向、一个输出、零在线安全几何查询；全部世界模型调用为0。在线几何/Head调用、参数、延迟与离线标签成本分别列账，不能把不同类型成本虚称完全相同。

CorrectionPlanner 原始 trace critic/IL/RL 依赖真实策略与特征，本轮不复现；固定 primitive 选择也不是 CorrectionPlanner 全系统复现。完整 Plan-R1 “仅改连续奖励”与 CorrectionPlanner 同标签对照仍未完成，不能在论文中填入其性能。

## 独立评价与退出条件

测试用自适应区间 SAT：中点若发生重叠即 collision witness；若中点固定分离轴的 gap 大于两个刚体顶点运动上界×半区间，则该区间安全；否则细分，最细0.1ms仍无法判断记 unknown。运动界由已获证书的限值和常速度周车给出。零、5mm、2cm、5cm buffer 分别检验；buffer 用同一分离裕量收紧，不等于精确欧氏膨胀距离。评估器采用不同时间查询机制，不是直接重用标签局部最小化器。证书只针对指定轨迹/障碍运动。

输出 proposal 碰撞率、接受碰撞率、unknown、拒判、终点 x 位移、接受位移代理、动力学证书、端点误差/兼容率、实际单核 CPU 生成耗时、模型参数/调用/几何查询。位移不是 nuPlan closed-loop progress；拒判乘零只用于代理，不称真实驾驶成绩。暖机延迟含 batch1 前向和51点轨迹物化，不含独立评估器；另报全部场景时间分布和评估总墙钟。

只有 RAW Bridge 稳定超过同标签固定 primitive 和投影残差，并具有非临界安全余量与真实模型支持，才考虑后续 GPU。本轮若等价、提升不稳定、只救毫米边界或真实输出缺失，则 NO-GO；不为追求正结论放宽动力学、追加标签或增加候选。
